# Sindid Arafat — Stark Protocol Portfolio & AI Terminal ⚡

A high-tech, Iron-Man-themed personal portfolio and mission terminal showcasing the product analysis, AI/ML research, systems engineering, and full-stack projects of **Sindid Arafat**.

Built for seamless deployment on **Vercel**.

---

## 🚀 Key Highlights & Modules

- **Stark Industries HUD Interface:** J.A.R.V.I.S. v4.2 telemetry status bar, real-time coordinates (Dhaka, Bangladesh), Mark LXXXV cyber-styling, corner brackets, and procedural Web Audio SFX with mute toggle.
- **Interactive 3D Arc Reactor Core:** Clickable palladium core with energy discharge pulses, frequency modulation, and live power status readouts.
- **GitHub Contribution Matrix & Arc Defender Game:**
  - Interactive contribution matrix reconstructing GitHub activity (2026, 2025, 2024, and All-Time).
  - Built-in arcade defense game: Repulsor rays target rogue Ultron bugs, combo multipliers, 100% Arc Reactor charging, and screen-clearing Unibeam blasts.
  - Draw/Paint mode for designing custom commit art.
- **Complete Technical Arsenal:** Covering Product & Business Analysis (PRDs, UAT, Jira, Figma, Stakeholder syncs), AI/ML (PyTorch, KAN, Transformers, Scikit-learn), Web/Backend, Languages, and Creative Suite.
- **29 GitHub Repositories Explorer:** Searchable, filterable repository index with direct links, star counters, and tags.
- **Mission Case Studies:** SkillSwap (MERN), Electrician Finder (PHP), Bank Loan Approval AI, Kolmogorov-Arnold Transformer (KAT), MADMAX Fury Road (OpenGL), and Simon Says (Arduino IoT).
- **Executive Dossier:** UIHP Innovation Hub Winner (ICT Division & The World Bank), 4x Dean's List scholarships, and The Duke of Edinburgh's International Award (Bronze).
- **Comms Terminal:** Direct encrypted message transmission form and interactive Stark CLI terminal.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Custom HUD Keyframes & Glows
- **Icons:** Lucide React + Custom SVG High-Tech Icons
- **Audio:** Web Audio API Procedural Synthesizer
- **Effects:** Canvas Confetti & Particle Blasts
- **Deployment:** Vercel (Configured via `vercel.json`)

---

## 💻 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

---

## 🌐 Deploying to Vercel

This repository is pre-configured with `vercel.json` for zero-configuration Vite deployment.

### Option 1: Vercel Dashboard (Recommended)
1. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
2. Import `sindidarafat/portfolio_sa`.
3. Vercel will auto-detect Vite as the framework.
4. Click **Deploy**!

### Option 2: Vercel CLI
```bash
npx vercel
```
