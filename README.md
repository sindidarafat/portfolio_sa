# Sindid Arafat — Personal Portfolio & Interactive Terminal ⚡

A modern, high-tech futuristic HUD personal portfolio showcasing the product analysis, AI/ML research, systems engineering, and full-stack projects of **Sindid Arafat**.

Built for seamless deployment on **Vercel** and **Cloudflare Pages**.

---

## 🚀 Key Highlights & Modules

- **Futuristic Cyber HUD Interface:** Live telemetry status bar, real-time coordinates (Dhaka, Bangladesh), neon corner brackets, and procedural Web Audio SFX with mute toggle.
- **Interactive 3D Energy Core:** Clickable holographic core with energy discharge pulses and live status readouts.
- **GitHub Contribution Matrix & Grid Defender Game:**
  - Interactive contribution matrix reconstructing GitHub activity (2026, 2025, 2024, and All-Time).
  - Built-in arcade defense game: Pulse cannons target rogue bugs, combo multipliers, 100% core charging, and screen-clearing Overdrive blasts.
  - Draw/Paint mode for designing custom commit art.
- **Complete Technical Arsenal:** Covering Product & Business Analysis (PRDs, UAT, Jira, Figma, Stakeholder syncs), AI/ML (PyTorch, KAN, Transformers, Scikit-learn), Web/Backend, Languages, and Creative Suite.
- **29 GitHub Repositories Explorer:** Searchable, filterable repository index with direct links, star counters, and tags.
- **Featured Project Case Studies:** SkillSwap (MERN), Electrician Finder (PHP), Bank Loan Approval AI, Kolmogorov-Arnold Transformer (KAT), MADMAX Fury Road (OpenGL), and Simon Says (Arduino IoT).
- **Executive Dossier:** UIHP Innovation Hub Inter-University Winner & National Round Qualifier (ICT Division & The World Bank), 4x Dean's List scholarships, and The Duke of Edinburgh's International Award (Bronze).
- **Interactive Contact & CLI Terminal:** Direct message form and interactive CLI terminal.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Custom HUD Keyframes & Glows
- **Icons:** Lucide React + Custom SVG High-Tech Icons
- **Audio:** Web Audio API Procedural Synthesizer
- **Effects:** Canvas Confetti & Particle Blasts
- **Deployment:** Vercel / Cloudflare Pages

## 💻 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
